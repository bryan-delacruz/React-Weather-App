# Weather App

Search a city and get its current weather, built with React in 2022.

**Live:** [weather-project-bdlc.vercel.app](https://weather-project-bdlc.vercel.app/)

## What's in it

- Search by city name against the **OpenWeatherMap** current weather API (metric units).
- Each city becomes a card with its minimum and maximum temperature; cards can be removed.
- City detail page (`/ciudad/:id`) and an About page, with React Router.
- An alert when the city is not found.

## Stack

React, React Router, Axios, CSS. Bootstrapped with Create React App.

```bash
npm install
npm start
```
